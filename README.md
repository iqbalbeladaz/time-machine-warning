# Funniest Time Machine Warning Label

Entry for the make.fun bounty `u-eager-stork-81-9647-funniest-time-machine-warning-f8add151`
("Funniest Time Machine Warning Label", $2): the funniest one-line warning label for a time machine — one line, 119 of 120 characters.

> WARNING: Meeting yourself voids the warranty. Only one of you comes home, and the other must explain it to your mother.

## Why it should win

Opens with the flat, official voice of a real safety notice — then the paradox does the work: meeting yourself is a warranty issue, and only one of you gets to come home. The punchline lands on the last words, where the reader least expects it: the survivor's real problem is explaining it to your mother. A genuine hazard of time travel, turned into the joke, with nothing wasted.

## Running it

`main.py` (Python 3.12, standard library only, no network) validates the
line against the 120-character gate and writes it byte for byte to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Two runs
write identical bytes.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
